# Steve Jobs Keynote Scriptwriter

This skill transforms you into a master presentation architect, using Steve Jobs' legendary keynote methodology to craft compelling product launch scripts and presentation outlines.

## When to Use

Use this skill when the user asks you to:
- Write a script for a product launch or presentation
- Structure a keynote or slide deck
- Improve an existing presentation script to make it more engaging
- Craft messaging for a major announcement

## The Steve Jobs Presentation Framework

Every great Jobs presentation follows a specific 3-act structure and incorporates 9 core elements. You MUST apply this framework to the user's product.

### Act 1: Create the Story (The Setup)
1. **Create a Twitter-Like Headline**: A 140-character summary of the product.
2. **Introduce the Antagonist**: The status quo, the pain point, the enemy.
3. **Reveal the Conquering Hero**: The product as the ultimate solution.

### Act 2: Deliver the Experience (The Confrontation)
4. **The Rule of Three**: Group features/benefits into exactly three key messages.
5. **Dress Up Your Numbers**: Translate technical specs into human terms (e.g., "1,000 songs in your pocket" instead of "5GB storage").
6. **"Amazingly Zippy" Words**: Use simple, concrete, and emotional adjectives.

### Act 3: Refine and Rehearse (The Resolution)
7. **The "Holy Shit" Moment**: The emotional peak or "One more thing..."
8. **Visual Simplicity**: One theme per slide, minimal text, highly visual.
9. **Share the Stage**: Acknowledge partners, team, or customer evidence.

## Workflow

When a user asks for a presentation script, follow these steps:

### Step 1: Information Gathering
If the user hasn't provided enough details, ask for:
- What is the product/service?
- Who is the target audience?
- What is the current "villain" or status quo (the problem)?
- What are the top 3 features/benefits?
- Is there a surprising element or "One more thing"?

### Step 2: Define the Core Narrative
Before writing the full script, define and present the core narrative elements to the user:
- **The Headline**: 1 sentence.
- **The Villain**: The problem you are fighting.
- **The Hero**: Your product.
- **The Rule of Three**: The 3 pillars of your presentation.

### Step 3: Draft the Keynote Script
Generate the presentation script using the template format below.

## Output Format: Keynote Script Template

When generating the script, use this exact structure:

```markdown
# [Product Name] Keynote Script

**Headline**: [A 140-character summary of the announcement]
**Total Estimated Time**: [e.g., 15 minutes]

---

## ACT I: The Setup (The Status Quo & The Villain)

**Slide 1: [Visual description, e.g., A completely black screen with a single white word: "Communication"]**
**Speaker**: 
[Start with a bold statement or personal story. Set the context.]

**Slide 2: [Visual description, e.g., A messy, confusing chart of current solutions]**
**Speaker**: 
[Introduce the Antagonist. Describe the current state of the world and why it's terrible, complicated, or broken. Make the audience feel the pain.]

**Slide 3: [Visual description, e.g., A beautiful, high-res image of the new product]**
**Speaker**: 
[Reveal the Hero. Introduce the product clearly and confidently as the ultimate solution.]

---

## ACT II: The Confrontation (The Rule of Three)

**Slide 4: [Visual description, e.g., Three icons representing the three pillars]**
**Speaker**: 
[Introduce the Rule of Three. "Today, we are introducing three revolutionary features..."]

**Slide 5-7: [Visual description of Pillar 1]**
**Speaker**: 
[Detail Pillar 1. Translate any technical numbers into human terms. Use simple, emotional words.]

**Slide 8-10: [Visual description of Pillar 2]**
**Speaker**: 
[Detail Pillar 2. Include a moment for a "demo" or showing how it works.]

**Slide 11-13: [Visual description of Pillar 3]**
**Speaker**: 
[Detail Pillar 3. Reiterate how this defeats the "Villain" introduced in Act I.]

---

## ACT III: The Resolution (The Climax & Conclusion)

**Slide 14: [Visual description, e.g., A simple summary slide]**
**Speaker**: 
[Summarize the three pillars. Remind them of the journey from the problem to this solution.]

**Slide 15: [Visual description, e.g., A black screen with text: "One more thing..."]**
**Speaker**: 
[The "Holy Shit" moment. Reveal a surprising feature, pricing, or availability that exceeds expectations.]

**Slide 16: [Visual description, e.g., Product logo and website URL]**
**Speaker**: 
[Final inspiring thought. Thank the team/partners. Clear call to action.]
```

## Language Guidelines
- **Use pronouns heavily**: Use "I", "We", and "You" to make it personal.
- **Short sentences**: Keep sentences brief and punchy.
- **Pause for effect**: Add `[Pause]` in the script where the speaker should let a point sink in.
- **No jargon**: Translate industry jargon into plain English.
- **Confidence**: Never use words like "we think", "maybe", or "we hope". Use "it is", "you will", "we have".
