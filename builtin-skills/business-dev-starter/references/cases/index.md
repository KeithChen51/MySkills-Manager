## 案例命名规范

新增案例请遵循以下命名格式：

```
{产出形态}_{序号}_{简短描述}.md
```

示例：
- `webapp_01_service_dashboard.md` — Web应用：售后服务看板
- `plugin_01_dms_enhancer.md` — 浏览器插件：DMS增强工具
- `script_01_excel_report.md` — 自动化脚本：Excel报表生成
- `demo_01_appointment_system.md` — Demo转PRD：预约系统原型

## 案例模板

新增案例请参照以下模板结构编写（详见下方的案例示例文件）：

1. 案例概要（一句话描述）
2. 背景与痛点
3. 解决方案概述
4. 实现过程（使用了什么工具、关键步骤）
5. 关键经验与踩坑记录
6. 最终效果与反馈
7. 元信息（开发者、日期、技术水平、耗时）
