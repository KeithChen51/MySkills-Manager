## 部署文档撰写要求

如需申请服务器资源，业务人员需自行撰写部署文档。以下是部署文档的标准模板：

### 部署文档模板

```markdown
# [应用名称] 部署文档

## 1. 应用概述
- 应用名称：
- 功能简述：
- 开发者：
- 目标用户：
- 预计访问量：

## 2. 技术栈
- 前端：（例如 React / Vue / 纯HTML）
- 后端：（例如 Node.js / Python / 无后端）
- 数据库：（例如 MySQL / SQLite / 无数据库）
- 其他依赖：

## 3. 资源需求
- CPU：
- 内存：
- 存储：
- 网络：（是否需要公网访问）
- 域名：（是否需要分配域名）

## 4. 部署步骤
（请详细列出从零开始部署此应用的每一步操作）

## 5. 环境变量与配置
（列出所有需要配置的环境变量）

## 6. 健康检查
（如何确认应用正常运行）

## 7. 备份与恢复
（数据备份策略，如适用）

## 8. 联系人
- 业务负责人：
- 技术支持：
```
