# 知识库导航

本文件是"业务自主开发启航"Skill知识库的主索引页。当用户选择"模块化导航"模式时，根据此文件引导用户找到所需信息。

## 模块一：开发路径指南

帮助用户了解不同产出形态的从0到1开发全流程。详见 `pathways/index.md`。

| 路径文件 | 适用场景 |
| :--- | :--- |
| `01_webapp_dev.md` | 独立Web应用开发（最常见路径） |
| `02_plugin_dev.md` | 浏览器插件增强现有系统 |
| `03_automation_script.md` | 自动化脚本与数据处理 |
| `04_demo_to_prd.md` | 用AI生成Demo后转化为PRD交付开发 |

## 模块二：成功案例库

展示内部业务人员自主开发的真实案例，供参考和学习。详见 `cases/index.md`。

案例按**产出形态**和**业务领域**双维度分类。

## 模块三：规范与资源中心

提供公司级的UI规范、部署流程和可用资源清单。详见 `standards/index.md`。

| 文件 | 内容 |
| :--- | :--- |
| `ui_spec.md` | 公司UI/设计规范 |
| `deployment_guide.md` | 集团部署流程与资源申请指南 |
| `system_landscape.md` | 现有系统与数字设备全景图 |
