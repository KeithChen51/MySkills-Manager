# 路径三：自动化脚本开发

> 适用于需要批量处理数据、自动化重复性工作的场景，如Excel数据清洗、报表自动生成、数据格式转换等。这是入门门槛最低的路径。

## 阶段总览

| 阶段 | 目标 | 预计耗时 | 关键产出 |
| :--- | :--- | :--- | :--- |
| 1. 问题描述 | 明确要自动化的工作内容 | 0.5天 | 输入/输出描述 |
| 2. AI生成脚本 | 用AI生成处理脚本 | 0.5-1天 | 可运行的脚本 |
| 3. 验证与调优 | 用真实数据测试 | 0.5-1天 | 验证通过的脚本 |
| 4. 固化与分享 | 形成可复用的工具 | 视情况 | 使用说明 + 脚本文件 |

---

## 阶段1：问题描述

**目标**：用"输入 → 处理 → 输出"的框架描述你的需求。

**模板**：
- **输入**：我有一个/一批 ____（例如：Excel文件，包含XX列）
- **处理**：我需要对它进行 ____（例如：按XX条件筛选，汇总XX数据）
- **输出**：最终我需要得到 ____（例如：一个新的Excel文件，包含汇总结果）

## 阶段3：验证与调优

**建议步骤**：
1. 准备一份小规模的测试数据
2. 运行脚本，检查输出是否符合预期
3. 如有问题，将错误信息和期望结果一起反馈给AI，让它修正
4. 用完整数据再次验证
