# 开发路径指南

本目录包含不同产出形态的从0到1开发全流程指南。每条路径都包含阶段划分、推荐工具、关键节点提示和注意事项。

## 路径一览

| 文件 | 路径名称 | 适用人群 | 典型产出 |
| :--- | :--- | :--- | :--- |
| `01_webapp_dev.md` | 独立Web应用开发 | 所有技术水平 | 数据看板、管理后台、业务工具 |
| `02_plugin_dev.md` | 浏览器插件增强 | 有一定Prompt经验 | DMS增强插件、CRM辅助工具 |
| `03_automation_script.md` | 自动化脚本开发 | 零基础即可 | Excel处理、数据清洗、报表生成 |
| `04_demo_to_prd.md` | Demo转PRD交付 | 零基础即可 | 可演示的原型 + 专业PRD文档 |

## 如何选择路径

如果用户不确定选择哪条路径，可参考以下决策逻辑：

- 需要一个**可视化的、可交互的界面** → `01_webapp_dev.md`
- 想在**现有Web系统上增加功能**而不改动原系统 → `02_plugin_dev.md`
- 需要**批量处理数据或自动化重复工作** → `03_automation_script.md`
- 只需要**展示想法给开发团队**，由他们来实现 → `04_demo_to_prd.md`
