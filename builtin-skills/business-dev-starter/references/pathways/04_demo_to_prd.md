# 路径四：Demo转PRD交付

> 适用于业务人员用AI生成功能Demo后，需要将其转化为专业的PRD文档交给开发团队实现的场景。这条路径不要求你自己完成部署，而是通过高质量的Demo和PRD来加速需求沟通。

## 阶段总览

| 阶段 | 目标 | 预计耗时 | 关键产出 |
| :--- | :--- | :--- | :--- |
| 1. 生成Demo | 用AI快速生成可交互原型 | 1-2天 | 可演示的前端Demo |
| 2. Demo转PRD | 用AI将Demo逆向工程为PRD | 0.5-1天 | 专业PRD文档 |
| 3. 评审与迭代 | 与产品/开发团队评审PRD | 1-2天 | 评审通过的PRD |
| 4. 交付开发 | 进入正式开发流程 | - | 排期确认 |

**PRD应包含的核心内容**：
1. 功能架构图（Mermaid格式）
2. 业务用户流程图
3. 页面规格说明（UI元素、交互逻辑、数据需求）
4. 业务边缘案例（冲突处理、库存联动、权限控制等）
