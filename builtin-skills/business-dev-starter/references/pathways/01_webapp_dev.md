# 路径一：独立Web应用开发

> 这是最常见的业务自主开发路径。适用于需要一个可交互的前端界面来承载业务功能的场景，如数据看板、管理后台、业务工具等。

## 阶段总览

| 阶段 | 目标 | 预计耗时 | 关键产出 |
| :--- | :--- | :--- | :--- |
| 1. 需求梳理 | 明确要做什么 | 1-2天 | 功能清单 + 页面草图 |
| 2. AI辅助开发 | 生成可运行的代码 | 2-5天 | 可本地运行的Web应用 |
| 3. 测试与优化 | 确保功能正确 | 1-3天 | 经过验证的应用 |
| 4. 部署上线 | 让其他人也能使用 | 1-3天 | 可访问的线上应用 |

## 阶段3：测试与优化

**目标**：确保应用功能正确、体验流畅。

**建议步骤**：
1. 自己先完整走一遍所有功能流程
2. 找1-2个同事试用，收集反馈
3. 将反馈整理后，用AI工具进行修改优化
4. 确认是否符合公司UI规范（详见 `standards/ui_spec.md`）
