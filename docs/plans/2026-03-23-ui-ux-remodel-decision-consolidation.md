## 2. 总体层（战略/品牌/范围）
### 2.1 产品与战略前提（Section 1）
- 阶段：Pre-product，组织内创业级内部开源产品。
- 核心问题：Skill 快速增长但效果不可见、管理路径不清。
- 核心价值主张：`Skill 到底起作用了吗？`
- 目标角色：服务效率部/业务发展部效率提升专员。
- 核心场景：周会、月度复盘；目标收益 `30-60 分钟/周/人`。

### 2.2 品牌与视觉硬约束（Section 2）
- Logo 不变。
- 调性：有品味、克制、专业，避免廉价工具后台感。
- 色彩：从品牌色板扩展；语义成功色采用高级绿色 `#2F7A66`。
- 绿色边界：仅用于成功/确认/完成语义反馈。

### 2.3 范围与结构（Section 3-4）
- 重塑范围：全量成立，但落地从“技能与工具管理”先行。
- 长期功能盘：本机技能/工具管理、使用记录统计、评测结果对比。
- 结构选型：技能与工具管理一体化；视觉方向：Prism Rational。

### 2.4 全局横向规范（跨模块）
- 全局时间展示统一北京时间（UTC+08:00）。
- 统一文字 token 与语义类，配套 Stylelint + 门禁 + 豁免治理。
- 通用设计语言冻结后复用，不重复定义。

### 3.1 A. 技能&工具基线框架（扫描/同步/Tab/Tools骨架）
- 覆盖范围：`5.0` - `5.67`（共 `68` 条）。
- 单页一体化承载 Skills/Tools，强调“扫描结果驱动动作”。
- 扫描是秒级反馈，不采用长等待；结果分为未收录/冲突/无变化三态。
- 冲突处理收敛为“看 diff + 选一个基准版本”，避免过度复杂化。
- Tools 首屏宽松可读，追踪优先于自动同步，主动作与状态层级清晰。

### 3.2 B. 使用记录&日志一体化（含 Top 技能）
- 覆盖范围：`5.68` - `5.131`（共 `64` 条）。
- “使用记录 + 日志”合并为一体，不再拆成用户常驻双页。
- 日志在同页大悬浮窗呈现（不遮挡侧边栏，可右上角或窗外关闭）。
- Top 技能作为高频入口，与日志过滤联动但不跳转到评测页。
- 日志可读性细节（时间、路径、展开、排序、提示）已全面冻结。

### 3.3 C. 全局文字体系与样式治理
- 覆盖范围：`5.132` - `5.188`（共 `57` 条）。
- 建立语义级文字 token 与角色类，统一标题/正文/说明文的跨页表达。
- 明确从局部到全局的改造顺序、验收口径、留痕模板和进度机制。
- 接入 Stylelint/门禁与豁免规则，确保规范长期可执行。
- 对“通用设计语言”采用冻结后复用，避免后续重复定义。

### 3.4 D. 使用记录架构收敛（Dashboard 并入）
- 覆盖范围：`5.189` - `5.206`（共 `18` 条）。
- 明确 Dashboard 即使用记录数据看板，不再作为独立心智页面。
- 退役旧 LogsPage，保留必要过渡与兼容窗口。
- 统一“概览 + 日志”主壳、默认锚点、时间档位、刷新反馈与返回锚点。
- 关闭行为与排序细则已冻结，保障主链路稳定。

### 3.5 E. 技能&工具合并后微交互深化
- 覆盖范围：`5.207` - `5.316`（共 `110` 条）。
- 一级导航为“技能&工具”，页头只保留“扫描本机技能”主按钮。
- 同步入口下沉到 Tools 卡片级动作；同步方向反转为“my-skills -> 工具路径”。
- 术语分离：Skills 域“收录到 my-skills”，Tools 域“下发到工具”。
- 围绕 Tooltip、成功/失败提示、spinner、无障碍播报与状态互斥做了完整冻结。

### 3.6 F. 评测页全面重塑
- 覆盖范围：`5.317` - `5.573`（共 `257` 条）。
- 评测页继承全局设计语言并形成独立叙事：结果优先、趋势可读、解释充分。
- 首屏核心指标冻结为：总通过率、本次vs上次提升、失败样本数、评测耗时。
- 提升值口径（三态、精度、缺失态、颜色、符号）和大量组件交互全部定稿。
- 历史弹窗、结果表格、图表、QuickChecks/Module Results 等细节完成高密度收敛。

### 3.7 G. Git 页面重塑
- 覆盖范围：`5.574` - `5.632`（共 `59` 条）。
- Git 页定位为“本机仓库技能同步治理工作台”，主任务链路明确。
- 仓库卡片、详情工作台、图谱弹窗、忽略规则弹窗等核心交互均已冻结。
- 空态、状态 pill、排序、默认去向、草稿保留、反馈留存等均有明确口径。
- 时间展示统一遵循北京时间与统一格式。

### 3.8 H. 设置模块重塑
- 覆盖范围：`5.633` - `5.654`（共 `22` 条）。
- 采用“左侧分类 + 右侧内容”双栏设置工作台，参考给定框架但页面内实现。
- 分类分组、默认选中、导航宽度、选中态、分段卡片、反馈位置全部冻结。
- 保存策略为分区独立保存/生效，不做全局保存。
- 分类切换未保存改动时弹确认（保留/丢弃/取消切换），并补齐信息密度/dirty 可见性/主操作可达策略。
